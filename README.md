# Transformers: roteiro de produção e demonstrações

Roteiro de um vídeo-apresentação de 35 minutos sobre Transformers, com demonstrações executáveis. Comece pelo [índice do roteiro](roteiro/README.md).

Para abrir as demos, rode o comando abaixo na raiz e acesse `http://localhost:8000/demos/01-self-attention/`:
