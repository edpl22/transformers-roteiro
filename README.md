# Transformers: roteiro de produção e demonstrações

Roteiro de um vídeo-apresentação de 35 minutos sobre Transformers, com a animação completa e demonstrações executáveis. Comece pelo [índice do roteiro](roteiro/README.md).

Rode o comando abaixo na raiz e acesse `http://localhost:8000/app/` para a animação, ou `http://localhost:8000/demos/01-self-attention/` para uma demo:

```bash
python -m http.server 8000
```
